INKWELL 7.34 FOR WINDOWS
========================
New in 7.32: Inkwell for Windows is a normal Windows program. It no longer
needs Python, and it has a real installer and a real uninstaller.

The older installer ("Install or Update Inkwell.bat") ran Inkwell through
Python. When Python or its window component was missing, Inkwell opened as a
page in the web browser where nothing worked, and there was nothing to
uninstall. That installer is retired.


PART A. INSTALL (OR UPDATE) INKWELL
-----------------------------------
1. If an older Inkwell still opens: File, Export library, and keep the file.
   (If it no longer opens, your documents are still on the computer, in
   %LOCALAPPDATA%\Inkwell\storage. The new installer keeps that folder and
   copies it to %LOCALAPPDATA%\Inkwell\backups before it changes anything.)

2. Get the installer, Inkwell-7.34-Windows-Setup.exe:
   from the GitHub release "Inkwell 7.34 for Windows (build N)" (under
   Assets), or build it yourself (Part C).

3. Double-click it. Windows may show "Windows protected your PC": choose
   "More info", then "Run anyway". (The installer is not signed with a paid
   certificate; that is the only reason for the warning.)

4. Follow the installer. It needs no administrator password. It installs
   Inkwell for you only, into %LOCALAPPDATA%\Programs\Inkwell, puts Inkwell in
   the Start menu, and removes the old Python-based shortcuts and program
   files. It never removes your documents.
   The Desktop shortcut is optional: from 7.38 the box "Also put Inkwell on
   the Desktop" is unticked, and an update with it unticked removes the old
   Desktop shortcut. Removing that shortcut by hand is safe too: it is only a
   link, and your documents are not in it. To pin Inkwell instead: Start,
   right-click Inkwell, Pin to Start or Pin to taskbar.

5. Open Inkwell. Look for "v7.34" beside the date at the top.
   If your documents are not there, choose File, Import library, and pick the
   file from step 1, or the newest backup in %LOCALAPPDATA%\Inkwell\backups.

Inkwell uses Microsoft Edge WebView2, which is part of Windows 11 and of
up-to-date Windows 10. If Inkwell says WebView2 is missing, install
"Microsoft Edge WebView2 Runtime" from Microsoft's website.


PART B. UNINSTALL
-----------------
Settings, Apps, Installed apps, Inkwell, Uninstall. (On Windows 10: Settings,
Apps, Inkwell, Uninstall.) Your documents stay in %LOCALAPPDATA%\Inkwell; to
remove them as well, delete that folder by hand after exporting anything you
want to keep.

The old Python-based Inkwell had no uninstaller. Installing 7.32 or later removes its
program files and shortcuts. Python itself is not needed by Inkwell any more;
whether you keep Python is your choice.


PART C. BUILD THE INSTALLER YOURSELF ON GITHUB (OPTIONAL)
---------------------------------------------------------
This package also holds everything GitHub needs to build the installer.
1. github.com, "+", New repository (private is fine), Create repository.
2. Unzip this package. Show hidden files (File Explorer, View, Show, Hidden
   items) so the folder ".github" can be seen.
3. On the new repository's page, "uploading an existing file": drag in
   EVERYTHING inside the package folder (.github, Inkwell-Windows, web, and
   the files beside them), then "Commit changes".
4. If ".github" is missing on the repository's page: Add file, Create new
   file, name it exactly  .github/workflows/build-windows.yml  and paste the
   text of "WORKFLOW build-windows.yml (copy).txt" into it.
5. Actions tab: "Build Inkwell for Windows" runs by itself (or press "Run
   workflow"). It takes about 10 minutes. It builds Inkwell.exe, tests that
   its companion server starts and answers, and makes the installer.
6. Releases (right-hand side): "Inkwell 7.34 for Windows (build N)", with
   the installer under Assets.
   A red "Publish a release" step: Settings, Actions, General, Workflow
   permissions, "Read and write permissions", Save, and run it again.


SCRIBA AND THE MICROPHONE
-------------------------
If Scriba says Windows refused the microphone: Settings, Privacy and
security, Microphone. Switch on "Microphone access" and "Let desktop apps
access your microphone". In this program Scriba transcribes with on-device
Whisper inside the page (downloaded once, then offline).


THE WRITING MODEL ON THIS COMPUTER (NEW IN 7.34)
------------------------------------------------
Engine, "Writing model on this computer": the panel marks the model
recommended for this computer's memory; press Install. It downloads once
(about 2.5 GB) and runs offline with the llama.cpp runtime inside
Inkwell.exe. Correct, Rewrite, Draft, Rewrite with a prompt and the prompt
library use it. The model is Qwen3 4B Instruct 2507, the best careful editor
measured on 6 October 2026 (details in INKWELL_HANDOFF_v7p34.txt). It needs
8 GB of memory or more. Every rewrite is checked: one that drops a citation
or number, or adds a name or number, is marked in red ("Use anyway").


YOUR OTHER DEVICES CAN USE THIS COMPUTER'S MODEL, AND THIS ONE ANOTHER'S
------------------------------------------------------------------------
1. Open Inkwell here. Engine, under "Sharing this computer's model":
   press "Share with my other devices on this Wi-Fi". It shows an address
   and a code. Keep Inkwell open while others use it.
2. If the computer asks whether to allow Inkwell on the network, choose
   Allow (Private networks only).
3. On the Fire tablet, iPhone or iPad, on the same Wi-Fi: Engine, "Your
   computer's model": type the address and the code, then "Connect to my
   computer".
4. New in 7.38, the other way round: this computer can use a stronger
   one's model, such as the Mac mini's. Engine, "Another computer's
   model": type that computer's address and code, then "Use that
   computer's model". When it is asleep or closed, this computer's own
   model stands in until it answers again.
Only the writing and voice tools are shared, and only with the code. Your
documents are never reachable from the network. "Stop sharing" closes it again.
