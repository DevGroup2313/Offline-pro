INKWELL 7.30 FOR MAC
====================
1. In your current Inkwell, choose File, Export library, and keep the file.
2. Unzip this package. Keep all its files together.
3. Double-click "Install or Update Inkwell.command".
   If macOS refuses to open it: open Terminal, type  zsh  and a space, drag
   the .command file into the Terminal window, and press Return.
4. Answer its questions. It works for a first install and for an update.
5. In Inkwell, open Scriba and press Record. Click Allow when macOS asks.

Your documents, models and settings are kept, and backed up first. The
backup folder is shown at the end; a copy of the library is put on your
Desktop.

The installer needs Python 3 and a C compiler, both part of Apple's command
line tools. If either is missing it says so; install them with:
    xcode-select --install
(This is not Xcode. It is a small separate download that works on Macs where
Xcode cannot be installed.)

Local transcription (Whisper) is optional. The installer offers it. Without
it, Scriba uses the Mac's own dictation engine where that is available.

Problems: see INKWELL_HANDOFF_v7p29.txt, section "If something goes wrong".
