INKWELL 7.38: THE WEB APP
=========================

WHAT IS IN THIS PACKAGE
-----------------------
The folder "Inkwell-web-7.38" is the finished web app. There is nothing to
build and no GitHub Actions is needed. No file in it is larger than 9 MB, so
the whole folder can be put online by dragging it into a browser.

(Before 7.38 this package was a kit that GitHub Actions had to build, and
one of its files, 26.9 MB, was too large for GitHub's browser upload, which
takes 25 MB at most. That is why it could not be put online or updated.)

Safari can add Inkwell to the Home Screen only from a web address, not from
a file. So the folder is put online once, at an address of your own.

BEFORE YOU UPDATE
-----------------
Open your current Inkwell, File, Export library, and keep the file.


PUT IT ONLINE THE FIRST TIME (choose one)
-----------------------------------------
A. Netlify (free, and the simplest)
   1. On a computer, open  https://app.netlify.com/drop  in a browser.
      Sign up or log in (free). A site dropped without an account is kept
      behind a temporary password until it is claimed.
   2. Unzip this package. Drag the folder "Inkwell-web-7.38" onto the page.
   3. Netlify shows the address, ending in .netlify.app. Keep it.
   Netlify advises keeping a deploy under 50 MB; this one is about 60 MB.
   If the deploy stalls, try once more, or use B.

B. GitHub Pages (free for a PUBLIC repository)
   1. github.com, "+", New repository, for example inkwell-site. Choose
      Public. Create repository.
   2. "uploading an existing file": drag in everything INSIDE the folder
      "Inkwell-web-7.38" (index.html, sw.js, manifest.webmanifest, and the
      icons and vendor folders). Commit changes.
   3. Settings, Pages. Source: "Deploy from a branch". Branch: main, folder
      / (root). Save. After a minute or two the address appears, of the form
      https://YOUR-NAME.github.io/inkwell-site/
   A public repository can be read by anyone; your documents are never in
   it (they stay on your devices). GitHub publishes Pages with its own
   Actions; if Actions is blocked on your account, the site may not
   publish. Then use A.


ON THE IPHONE OR IPAD
---------------------
1. Open the address in Safari.
2. Share, "Add to Home Screen", Add.
3. Open Inkwell from the Home Screen once while online, so it keeps its
   files for offline use.


UPDATING LATER (each new version)
---------------------------------
1. In the old Inkwell: File, Export library.
2. Netlify: open your site in Netlify. Under "Production deploys", drag the
   new folder onto the drop area.
   GitHub: in your site repository, "Add file", "Upload files", drag in
   everything inside the new folder, Commit. The old files are replaced.
3. Open Inkwell once while online. From 7.38 the new version shows at the
   first opening. The first update away from 7.37 or older may need a
   second opening, because the old version's offline copy answers first.
Look for "v7.38" beside the date at the top.


YOUR DOCUMENTS
--------------
- The web app keeps its own library in the browser, separate from the
  apps. Updating the site at the same address keeps it.
- A NEW address (for example, moving from GitHub to Netlify) starts with
  an empty library: File, Import library, and choose the exported file.
- Export regularly: a browser may clear a web app's storage, for example
  when the device is short of space.


NEW IN 7.38
-----------
- Rewrite with a prompt now works with no writing model at all. Every
  prompt in the library does something on this device: rules rewrite where
  they can keep the meaning, and each change says what it was and why. For
  what only you can write ("Show, don't tell", "Signpost the argument"), a
  coach points to the exact words, says how, and checks your own try.
- The seals are pressed into the wax; Schedae's button is a quill on
  parchment. The app icons are redrawn; on an iPhone or iPad the home
  screen icon sits on the seal's own cream.
- Schedae: "Send to Tabula"; six new note colours, by day and by night; each
  colour's name shows when you hover over it, as do the names of the symbol
  buttons everywhere.
- Right-click Paste works with text copied from other apps.
- The web app cannot reach the Mac mini's model: a secure web page may not
  call a plain address on the home network. The iPhone and iPad app can.


OFFLINE, AND THE MODELS
-----------------------
- After the first visit the web app works with no internet: the rules
  engine, spelling, Scriba's page, Fontes and Cite.
- On a laptop or desktop, Engine, "Writing model inside this window" can
  install a writing model in the page (about 850 MB, once; it needs
  WebGPU, as in Chrome or Edge). On a phone or tablet the web app offers
  no writing model: the system closes a page that takes that much memory.
- Engine, "Turn on the grammar model" (about 124 MB, once) adds careful
  grammar suggestions. Scriba can find the speakers in a recording (about
  33 MB, once). Both then work offline.


PROBLEMS
--------
- The address shows "404": wait a few minutes. On GitHub, check that
  index.html is at the top of the repository, not inside a folder.
- The old version still shows: close Inkwell fully and open it again while
  online.
- A model will not start: Engine, "Diagnose this device", and send me the
  report.
